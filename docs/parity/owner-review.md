# Owner review: user-visible changes from the old app to the new app

This is a plain-language list of every difference between the old InnyTypes app and the new one that a person using the app could actually notice — a button, a window, a tab, a setting, a command, a message, or something the app used to do for you. Purely internal, behind-the-scenes changes (how the program is built, process bookkeeping, the old helper/host split, internal messaging between parts of the program) are left out; they don't affect what you see or do.

Each numbered item below groups together every old test that covered one real behaviour. **Was** describes the old app; **Now** describes the new one, or says the behaviour is gone. **Tests** gives how many old checks covered it, and their names, so you can trace it back to the source list if you want to. **Flag: YES** marks anything that looks like a genuine loss you might want back, rather than a deliberate, equivalent replacement.
